# Task Completion Checklist

Before considering a task complete, ensure the following:

1. **Linting**: Run `npm run lint` and fix any introduced errors.
2. **Build Test**: Run `npm run build` to ensure the project still builds correctly (especially after updating dependencies or changing layouts).
3. **SEO Check**: If a new page was added, ensure it has proper metadata and is included in `src/app/sitemap.ts`.
4. **Brand Consistency**: Ensure the primary brand color `#42d9de` is used for all major UI elements (buttons, gradients, icons).
5. **Mobile-First**: Verify that changes look good on mobile screens (Next.js dev server at http://localhost:3000).
6. **Phone Number**: Ensure any phone numbers used are the updated `1877-3924`.
7. **Commit Changes**: Use clear and descriptive commit messages following the established style.
