# Suggested Commands

## Development
- `npm run dev`: Start the Next.js development server.
- `npm run 즉시확인`: Start the Next.js development server with Turbopack enabled (faster).
- `🚀_로컬서버실행.bat`: Windows batch script to start dev server and automatically open the browser at http://localhost:3000.

## Production
- `npm run build`: Build the application for production.
- `npm run start`: Start the production server after building.

## Quality Assurance
- `npm run lint`: Run ESLint to check for code quality issues.

## System Utilities (Windows)
- `dir`: List files and directories.
- `findstr`: Search for patterns in files.
- `git`: Version control commands (standard git commands apply).
