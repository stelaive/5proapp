# 디자인 진단 및 메인 페이지 수정안 (5prosky.com)

> 출처: 5PROSKY Search Growth Report
> 아래 "화면 관찰"은 첨부 이미지 기준. "권장"은 개선 제안이며 결함 확정이 아님.

## 핵심 판단

5% 환급은 기억에 남는 차별점이지만, 현재 화면은 혜택과 앱 소개에 무게가 쏠려 있음. 검색 고객이 먼저 확인하려는 "내 지역에 오는가, 어떤 장비가 필요한가, 얼마인가, 믿고 맡길 수 있는가"를 메인과 별도 정보 페이지에서 해결해야 함.

## 화면 진단 표

| 화면 관찰 | 수정 방향 | 완료 기준 |
|---|---|---|
| 오렌지 CTA와 5% 강조가 뚜렷함 | 색상 체계는 유지, 서비스명·지역·견적 동선 강화 | 첫 화면에서 제공 서비스와 문의 방법을 이해 |
| 지갑 앱 이미지가 중심 | 실제 장비·작업 현장 사진을 주 이미지로, 환급 UI는 보조로 | 사진의 작업·지역·촬영 맥락을 설명 |
| 배경 현장이 매우 어두움 | 텍스트 영역에만 어두운 처리를 집중 | 장비 형태와 현장 분위기를 식별 |
| 상단 메뉴가 작은 크기 | 장비·비용·지역·사례를 앞에 배치, 기사 모집은 보조 메뉴 | 견적 탐색과 기사 가입 경로 구분 |
| 긴 공백과 어두운 빈 영역 | 실제 렌더링 검증 후 불필요한 고정 높이·숨김 해소 | 스크롤 전후로 핵심 콘텐츠 누락 없음 |
| 전화·앱 중심 문의 동선 | 문자·웹 견적 또는 실제 운영 채팅 추가 | 통화 어려운 고객도 요청 완료 가능 |
| FAQ가 화면 아래 | 비용·배차·장비 핵심 답변을 위쪽에도 배치 | 긴 페이지를 훑지 않아도 답 확인 |

## 가장 먼저 검증할 문제: 중앙 공백 & 하단 검은 영역

실제 페이지의 빈 영역인지, 스크롤 애니메이션이 캡처 시점에 실행되지 않은 것인지 미확인. **실제 기기에서 위→아래 스크롤, 새로고침, 느린 연결, 애니메이션 최소화 설정에서도 내용이 나타나는지 검사 필요.**

공백이 재현되면 우선 수정. 핵심 내용이 화면 진입 이벤트 후에만 보이도록 숨겨져 있다면 기본 표시 상태 + 오류 시 대체 표시를 마련.

## 디자인 기준 (목표치, 실측 아님)

- 모바일 본문: 16~18px, 보조 문구는 읽기 쉬운 대비
- 버튼 터치 영역: 약 44px 이상
- 360/390/430px 폭 + 데스크톱에서 가로 넘침, 고정 버튼의 본문 가림, 메뉴 겹침 확인
- FAQ는 키보드 조작과 펼침 상태 전달 지원
- 작업 영상엔 자막·텍스트 요약 부착
- 현장 사진은 과도한 장식 이미지로 대체 금지, 실제 자료 사용 (개인정보·차량번호 공개 범위 검토)

## 메인 페이지 문구 수정안

### 첫 화면 (서비스 이해 → 견적 → 5% 혜택 순)

- **상단 보조 문구:** 스카이차 임대 · 현장 조건에 맞춘 배차 상담
- **H1:** 스카이차, 현장에 맞게 부르고 이용료 5% 돌려받으세요
- **본문:** 작업 지역과 날짜, 높이를 알려주세요. 현장 조건에 맞는 장비와 비용을 안내합니다. 5% 환급 대상과 지급 조건도 함께 확인하세요.
- **주 버튼:** 배차·견적 문의 / **보조 버튼:** 비용 기준 보기

> ⚠️ 전제: 실제 5% 환급 제도가 있어야 사용. 일부 고객/거래만 대상이면 "대상 이용 건 5% 환급"처럼 범위 명시. "즉시 지급", "24시간 출동", "전국 어디나"는 운영 사실이 확인될 때만 사용.

### 섹션 구성 순서

| 순서 | 섹션 제목 초안 | 필수 내용 |
|---|---|---|
| 1 | 어느 지역에서 작업하시나요? | 실제 배차 지역·접수 조건·상세 페이지 |
| 2 | 스카이차 비용, 어떤 조건으로 달라지나요? | 시간·장비·현장 조건별 기준표 |
| 3 | 현장에 맞는 장비를 확인하세요 | 실제 제공 장비·선택 상담 |
| 4 | 비슷한 작업 현장을 확인해 보세요 | 날짜·지역·장비·작업 설명을 가진 실제 사례 |
| 5 | 이용료 5%, 어떻게 돌려받나요? | 신청·산정·지급·예외·규정 링크 |
| 6 | 견적부터 작업까지 이렇게 진행됩니다 | 문의 → 현장 확인 → 견적·배차 확정 → 작업·정산 |
| 7 | 자주 묻는 질문 | 비용·당일 배차·현장 준비·취소·환급 |
| 8 | 작업 정보를 남겨주세요 | 전화·문자/웹 문의·사업자 정보 |

### 기존 공감 문구 개선

"스카이차 부를 때마다 이런 적, 없으세요?" → **"견적 전에 확인할 세 가지"**로 변경 권장

카드 내용: "작업 위치와 날짜 / 필요한 높이와 작업 내용 / 차량 진입과 설치 공간"으로 구성. 경쟁 업체를 막연히 불신하게 만드는 표현보다 실제 준비를 돕는 방향으로.
