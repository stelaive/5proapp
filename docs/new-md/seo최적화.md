# SEO 최적화 (5prosky.com)

> 출처: 5PROSKY Search Growth Report (2026.09.07 조사 기준)
> 이 문서는 화면 진단·공개 자료·공식 지침을 근거로 한 수정 명세이며, 실측 순위·트래픽·속도 점수는 포함하지 않음.

## 우선순위 요약

| 우선순위 | 할 일 | 기대 효과 |
|---|---|---|
| 1 | 접속·색인·본문 렌더링 검증 | 검색엔진과 고객이 핵심 정보를 읽을 수 있음 |
| 2 | 메인 정보 순서와 비용·환급 설명 수정 | 문의 전 불확실성 감소 |
| 3 | 실제 운영 지역·장비·작업 사례 페이지 구축 | 구체적 검색 의도 대응 |
| 4 | 플레이스·사업자 정보·실적 측정 정비 | 지역 신뢰 + 예약 성과 관리 |

## 기술 SEO 점검 항목 (개발자 전달용)

모든 항목은 "현재 구현 미확인" 상태의 점검 목록이며, 결함이 확인된 항목만 수정.

| 우선순위 | 항목 | 검증·수정 기준 |
|---|---|---|
| P0 | 접속·상태 코드 | 핵심 공개 URL 정상 응답, 잘못된 경로는 실제 404/410, CDN·방화벽에서 검색 로봇/사용자 접근 확인 |
| P0 | 색인 지시 | 의도치 않은 noindex·X-Robots-Tag·robots 차단 여부 확인 (robots 차단을 개인정보 보호 수단으로 쓰지 않음) |
| P0 | 본문 렌더링 | URL 검사에서 메인·비용·FAQ·지역 링크가 읽히는지 확인, 스크롤/클릭 후에만 정보가 뜨는지 검증 |
| P1 | 대표 URL | HTTPS + 대표 호스트(www) 일관성, 중복 페이지 canonical 확인, 지역 페이지들을 전부 홈으로 canonical 처리 금지 |
| P1 | 사이트맵 | 정상 공개 + 대표 URL 포함, 리다이렉션/오류/noindex URL 제외, 실제 변경 시에만 lastmod 갱신, 구글+네이버 양쪽 제출 |
| P1 | HTML 정보 | 고유 Title·요약, 명확한 H1/하위제목, 이미지 속 텍스트만으로 정보 전달 금지, 실제 링크 사용 |
| P1 | 모바일·속도 | PageSpeed Insights + 실기기 측정, LCP 2.5초/INP 200ms/CLS 0.1 이하 목표 |
| P1 | 이미지·JS | 주요 이미지 압축·크기 예약, 하단 이미지 지연 로딩(첫 화면 주요 이미지는 지연 금지) |
| P1 | 구조화 데이터 | 실제 조직/사업체 정보와 일치, 가짜 지점·평점·요금 금지, 검증 도구 통과 |
| P2 | 도메인 이전 | 이전 도메인 관리 가능하면 구 URL별 새 URL로 301, 관리 불가면 외부 공식 링크부터 정정 |

## 사이트 구조 제안

기존 경로가 같은 역할을 하고 있으면 그 URL을 우선 활용. 아래는 신규 설계 예시.

| 경로 | Title 초안 | 핵심 내용 |
|---|---|---|
| / | 스카이차 임대·비용 상담 \| 5프로돌려주는스카이차 | 서비스·지역·비용·실적·환급 요약 |
| /pricing/ | 스카이차 비용 안내 | 시간·장비별 견적 기준 | 자사 승인 가격·추가비용·VAT |
| /areas/ | 스카이차 배차 지역 안내 | 실제 운영 지역과 하위 페이지 링크 |
| /areas/suwon/ | 수원 스카이차 임대·비용 상담 | 수원 운영 확인 후 공개, 지역 사례·조건 |
| /equipment/ | 스카이차 장비 안내 | 제공 장비 비교, 모델별 상세 |
| /services/sign-work/ | 간판 작업 스카이차 임대 | 실제 지원 작업 범위·사례 |
| /cases/ | 스카이차 작업 사례 | 지역·장비별 현장 기록 |
| /cashback/ | 스카이차 이용료 5% 환급 | 산정 기준·시점·신청·예외 |
| /about/ · /contact/ | 회사 소개 / 견적 문의 | 사업자·운영 방식 / 상담 접수 |

**메인 Meta Description 초안:**
> 스카이차 임대 전 작업 지역과 날짜, 높이, 현장 사진을 알려주세요. 배차 가능 여부와 장비·작업 조건에 따른 비용을 안내합니다. 이용료 5% 환급 대상과 지급 조건도 확인하세요.

**내부 연결 원칙:** 홈 → 비용·지역·장비·사례로 실제 링크 연결. 각 지역 페이지는 그 지역 사례·관련 장비·견적 버튼과 연결. 버튼도 실제 URL을 가진 링크로 구현.

## 키워드 전략

검색량·난이도·CPC는 미확인. 지역명은 예시이며 실제 배차 기록/수익성으로 확정 필요.

| 우선순위 | 후보 검색어 | 목적지 |
|---|---|---|
| A | 수원 스카이차, 화성 스카이차, 평택 스카이차 | 지역 페이지 / 배차범위·사례·견적 |
| A | 스카이차 비용, 스카이차 1시간 비용, 하루 임대료 | 비용 페이지 / 시간·장비·추가비용·VAT |
| A | 수원 스카이차 비용, 화성 스카이차 임대 | 지역 페이지의 비용 섹션 |
| A | 간판 작업 스카이차, 외벽 작업 스카이차 | 작업별 페이지 / 현장조건·사례 |
| B | 1톤/3.5톤/5톤 스카이차 | 장비 페이지 / 모델별 높이·반경 |
| B | 굴절 스카이차, 고소작업차 임대 | 장비/서비스 안내 |
| B | 스카이차 당일 배차, 야간 스카이차 | 운영 가능 여부 안내 |
| B | 스카이차 사다리차 차이, 스카이차 견적 준비 | 가이드 콘텐츠 |
| A | 5프로돌려주는스카이차, 5프로 스카이차 | 홈·브랜드 소개 |
| C | 스카이차 기사 가입, 스카이차 제휴 | 파트너 페이지 (고객 예약과 분리) |

**확장 순서:** 브랜드·비용 → 핵심 지역 3~5곳 → 실적 있는 작업 유형 → 제공 장비 → 인접 지역. 지역명만 바꾼 페이지 대량 생성 금지.

**지역 선정 기준:** 최근 90일 문의·배차 기록의 지역별 문의 수, 예약률, 장비 공급 가능성, 이동 비용, 건당 이익 비교. 검색 수요만 많고 배차 어려운 지역은 후순위.
