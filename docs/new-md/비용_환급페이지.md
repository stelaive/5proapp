## 자사 비용표에 반드시 넣을 항목

| 항목 | 게시 기준 |
|---|---|
| 장비 | 톤수만으로 높이를 확정하지 말고 실제 모델·제원과 연결 |
| 시간 | 기본·반나절·하루의 시간 정의, 대기·이동 포함 여부 |
| 금액 | 확정가/시작가/참고 견적 구분, 적용 지역·일자 명시 |
| 추가 조건 | 야간·주말·이동·주차·현장 변경 등 실제 비용 발생 기준 |
| 세금·정산 | VAT 포함/별도, 결제·증빙 제공 방식 명확화 |
| 견적 확정 | 사전 정보와 현장 조건이 다를 때 재안내·동의 절차 |

가격 공개가 어려우면 임의의 최저가를 넣지 않음. 우선 견적 구성 항목을 공개하고, 검토가 끝난 실제 작업의 조건부 견적 사례를 추가. **경쟁사 가격을 자사 가격처럼 사용하지 않음.**

## "즉시 현금 반환" 문구와 앱 지갑 화면의 관계 설명 필요

현재 화면은 즉시 현금 반환을 기대하게 만드는 문구와 앱 지갑을 함께 보여줌. 실제로는:
- 적립 후 출금 신청인지
- 결제 완료 후 계좌 입금인지
- 지급 대기 기간이 있는지

→ 하나의 흐름으로 명확히 설명 필요.

## 확정해야 할 환급 정책

| 확정할 정책 | 고객이 볼 답 |
|---|---|
| 환급 대상 | 누가·어떤 주문·어떤 결제 수단에서 받을 수 있는가 |
| 산정 금액 | VAT·추가요금·할인 적용 전후 중 어느 금액의 5%인가 |
| 지급 조건 | 신청 필요 여부·최소 출금액·지급 시점·실패 시 문의 |
| 예외 | 취소·부분환불·중복 혜택·법인 거래 처리 |

**계산 설명 예시** (산술 예시일 뿐, 실제 이용료 아님):
> 환급 대상 금액이 400,000원인 경우 5%는 20,000원입니다.

공급가와 VAT, 실제 결제액, 환급액을 별도 행으로 보여줘서 체감 비용 오해 방지.
