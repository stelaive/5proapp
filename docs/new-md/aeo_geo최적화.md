# AEO·GEO 최적화 (5prosky.com)

> 출처: 5PROSKY Search Growth Report

## 개념 구분

- **SEO**: 발견·이해·색인을 돕는 작업
- **AEO**: 질문에 바로 답하도록 구성하는 작업
- **GEO**: 생성형 답변(AI)이 인용할 수 있는 근거를 만드는 작업

Google은 이를 기존 검색 최적화의 연장으로 설명함.

## 2026년 기준 제외할 낡은 제안

- Google FAQ 확장 검색결과는 2026년 5월 7일부로 종료됨. FAQ 자체는 고객 질문에 답하기 위해 유지하되, FAQ 마크업으로 확장 노출을 기대하지 않음.
- Google은 llms.txt가 자사 검색 가시성·순위에 도움이 되거나 해가 되지 않는다고 명시함.

## 답변 블록 구성 원칙

**결론 → 조건 → 실제 근거 → 다음 행동** 순서로 구성.

| 질문 | 공개 답변 초안 (운영 확인 후 게시) |
|---|---|
| 스카이차 비용은 어떻게 정하나요? | 작업 시간과 장비, 현장 조건에 따라 달라집니다. 지역·날짜·높이·작업 내용·현장 사진을 보내주시면 견적을 안내합니다. 확정 가격의 포함·제외 항목은 비용 안내에서 확인하세요. |
| 오늘도 배차가 가능한가요? | 당일 가능 여부는 지역, 시간, 필요한 장비의 예약 상황을 확인한 뒤 안내합니다. 접수만으로 배차가 확정되지는 않습니다. |
| 장비는 높이만 보고 고르면 되나요? | 높이뿐 아니라 작업 위치까지의 거리, 진입·설치 공간과 실제 장비 제원을 함께 확인해야 합니다. 현장 사진을 보내 상담받아 주세요. |
| 5%는 언제 받나요? | 운영 정책 확정 후 대상·산정 금액·신청 방법·지급 시점을 한 답변으로 게시합니다. 미확정 상태에서 "즉시"라고 쓰지 않습니다. |

## 원본 데이터가 장기 경쟁력

실제 사례에 아래 요소를 포함:
- 지역·작업월·장비 모델·선정 이유·작업 범위·소요시간·비용 포함 조건·사진·검토자

기록이 쌓이면 지역별 작업 통계 작성. **사실 없는 후기·전문가·실적 수치는 만들지 않음.**

## AI 검색 관련 확인 사항

- Google AI 기능은 색인·스니펫 가능 상태, Search Console의 생성형 AI 포함 설정 확인 필요
- 다른 AI 서비스는 별도 시스템이므로 같은 조치가 노출을 보장하지 않음 → 각 서비스의 최신 공식 크롤러 정책·실제 인용 결과를 별도 검증
- Google AI 검색 유입은 Search Console Web 실적에 포함되므로, 전체 증가분을 전부 AI 성과로 해석하지 않음
- AI 추천과 실제 출처 링크 인용은 구분해서 봐야 함

## AI 인용 측정 방법

고정 질문 20개를 월별 반복 → 서비스·날짜·질문·응답·출처 URL 저장 → **인용 횟수/검사 횟수**로 표기 (표본 측정임을 항상 명시)
