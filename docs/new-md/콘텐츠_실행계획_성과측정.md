## 사례 페이지 공통 양식

- **제목:** [실제 지역] [작업 종류] 스카이차 작업 사례
- **상단 요약:** 작업월 / 지역 / 장비 모델 / 작업 범위
- **본문:** 현장 제약 → 장비 선정 이유 → 수행 내용 → 소요시간·견적 조건 → 고객이 준비할 사항
- **하단:** 현장 검토자·최종 확인일 / 관련 지역·장비 / 견적 문의

주소·고객명·사진은 공개 가능한 수준으로 처리. 작업 높이와 안전 가능 여부를 글만 보고 확정하도록 유도하지 않고, 실제 장비 제원과 담당자 현장 확인으로 연결.
