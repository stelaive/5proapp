# AEO·GEO 콘텐츠 적용 기록

작업일: 2026-10-15. 로컬 lee-clean에 반영. 이번 변경의 커밋·푸시·실서버 배포는 수행하지 않았다. 이전 Git 업로드 작업의 로컬 이력 정리는 별개의 미완료 상태이므로 이번 콘텐츠 변경과 섞어 처리하지 않았다.

## 주제와 질문

- 브랜드: 5프로돌려주는스카이차(5프로스카이차).
- 주제: 스카이차 대여 비용과 간판작업 장비 선택·견적 준비.
- 대표 질문: “스카이차비용은 얼마이고, 간판작업에는 어떤 장비가 필요한가요?”
- 타깃: 간판·외벽 작업용 장비를 발주하는 시공업체, 현장 담당자, 시설관리자.
- 전환: 작업 조건을 준비한 전화 상담 및 예약.
- 수요: 실제 질문 빈도·검색량은 제공되지 않았으므로 대표 질문은 사업 맥락에 따른 가설이다.

## 작성과 구현

1. 메인·가격표·지역 상세 28개·광역 허브 3개에 질문형 제목과 핵심 답변 3개를 추가했다. 총 33개이며 본문은 초기 HTML에도 나온다.
2. 가격표는 H1 바로 다음에 핵심 답변을 배치했다. 회사·서비스 정의, 작성 주체 및 작성일, 근거 가격표 링크를 표시했다. 기존 URL과 검색 타이틀은 유지했다.
3. 자사 기준 요금으로 1톤~3.5톤과 5톤의 동일 시간 비교표를 작성했다. 가격표·요약·FAQ·원고는 같은 요금 데이터를 참조한다. 시장 평균·모든 현장의 확정 결제금액으로 표현하지 않는다.
4. ‘5프로의 견적 4가지 확인: 높이·거리·시간·설치 공간’을 이 안내의 편집 프레임워크로 제안했다. 기존에 검증된 회사 고유 노하우, 수상·특허·독점 방법으로 주장하지 않는다.
5. 간판 교체의 준비 절차는 ‘가정 예시’로 표시했다. 실제 작업 기록·고객 후기·전환 실적을 만들지 않았다. 실제 사례가 확보되면 위치·작업 범위·시간·장비·비용 포함 조건을 확인하여 추가할 수 있다.
6. 장비 비용과 간판 제작·설치 인력·처리 비용을 분리하고, 세금·추가 비용·대기/초과 시간·실제 장비 제원 등 확인할 조건을 명시했다.
7. 홈페이지의 즉시 현금 지급 문구를 기존 FAQ의 ‘작업 후 포인트 적립 → 출금 신청 → 계좌 지급’ 흐름에 맞췄다. 고정 요금만 강조하던 FAQ도 현장 조건에 따른 최종 견적 확인으로 교정했다.
8. 브랜드 정의와 alternateName을 공통 Organization에 반영하고 홈페이지 WebSite 정보로 사이트 이름을 명시했다. 화면 문답과 FAQ JSON-LD는 같은 데이터로 생성한다. 구조화 데이터를 AI 인용을 위한 특별한 필수 마크업으로 주장하지 않는다.
9. 기존 llms.txt의 확정적인 세금·항상 배차·비용 불변 문구와 중복 가격 수치를 정리하고 실제 가격표·조건 본문으로 연결했다. 파일은 참고 안내일 뿐 인용·검색 순위·학습을 보장하는 수단이 아니다.
10. 기존 robots.txt의 검색·학습 봇 허용 정책은 변경하지 않았다. 허용 상태는 실수집, WAF 통과, 모델 학습 반영 또는 AI 인용 완료를 의미하지 않는다.

## 실제로 확인한 근거

- 2026-10-15 공개 `/pricing` HTML을 읽어 20만·25만·35만·55만·45만·65만원이 표시됨을 확인했다.
- 자체 가격 원본: `src/lib/priceData.ts`. 지역 안내의 기존 요금 수치도 유지했다.
- 작성한 브랜드 정의와 서비스 범위는 기존 사이트 맥락에 따른 설명이며 사업자 등록증·장비 검사 기록을 새로 검증한 것은 아니다.
- 부가세 포함/별도 정책은 앞선 페이지 간 충돌 이후에도 운영자 확인이 필요하다. 이번 문구는 최종 견적 확인을 안내하며 세금 정책을 정하지 않는다.

## 검증

- TypeScript 검사 통과.
- Next.js 배포용 빌드 성공 및 정적 페이지 생성 성공.
- 배포용 서버에서 기존 SEO 검사에 답변 요약·브랜드 정의·2026-10-15 작성일·수치/가정/한계 표현 검사를 추가해 33개 페이지 모두 통과.
- 대표 URL·고유 메타데이터·H1/main·가격표 앵커·지역 연결 및 5개 리디렉션/404 검사 통과.
- 모바일 390px에서 가격표 요약 3개와 FAQ 펼침, 가로 넘침 여부를 확인했다. 성능 지표나 AI 답변 인용률 실측은 아니다.
- AI 인용이나 학습 반영을 테스트한 것은 아니다. 실제 배포·수집·색인은 별도로 확인해야 한다.

## 성과 검증 후속

- 배포 후 대표 URL이 최신 본문으로 수집·색인되는지 확인한다.
- Google Search Console의 제공되는 검색 및 생성형 AI 보고서를 확인하고, 실제 접근 가능한 보고서 범위 내에서 노출·클릭·도착 URL을 비교한다.
- ChatGPT 등에서 들어오는 식별 가능한 참조 유입과 유효 상담·예약을 구분해 측정한다. 참조 정보 누락은 미유입의 증거로 단정하지 않는다.
- 대표 질문을 고정하여 날짜·서비스·로그인/지역 조건·모델·웹 검색 사용 여부·답변·인용 URL을 기록한다. 단일 답변 결과를 보편적인 AI 순위로 일반화하지 않는다.
- 실제 시공 사례와 확정 운영 정책을 확보해 보강한다. 현재 원고만으로 가장 신뢰할 출처, 순위 상승, 모델 학습을 보장하지 않는다.

- [Google AI 기능과 웹사이트](https://developers.google.com/search/docs/appearance/ai-features): 텍스트 접근성, 내부 링크와 화면·구조화 데이터의 일치를 안내한다.
- [Google 문서 변경 기록](https://developers.google.com/search/updates): 2026년 5월 FAQ 리치 결과 종료 및 6월 문서 제거를 확인했다. FAQ를 작성하더라도 이 기능의 노출을 약속하지 않는다.
- [OpenAI 공식 크롤러 문서](https://developers.openai.com/api/docs/bots): OAI-SearchBot 검색 수집과 GPTBot 학습 수집이 별개이며 ChatGPT-User는 사용자 요청에 따른 접근이라고 설명한다. 공식 페이지를 직접 열어 확인했다.
