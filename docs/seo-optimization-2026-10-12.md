# 메인·가격표·지역 페이지 SEO 적용 기록

작성일: 2026-10-12. 대상: www.5prosky.com, lee-clean 로컬 소스. 실서버 배포 및 검색엔진 재수집 요청은 수행하지 않았다.

## 검색어와 도착 페이지

| 페이지 | 핵심 검색 의도·검색어 | 보조 검색어·본문 | 전환 |
|---|---|---|---|
| `/` | 스카이차 대여, 고소작업차 임대 | 간판작업 스카이차, 간판 설치·교체·철거, 외벽 보수 | 현장 조건으로 전화 견적 |
| `/pricing` | 스카이차가격, **스카이차비용**, 스카이차 가격표 | 스카이차 대여 비용, 1톤·3.5톤·5톤 비용, 1시간·반나절·하루 대여료, 간판작업 장비 비용 | 총비용·추가비용 확인 후 상담 |
| 지역 상세 28개 | 지역명+스카이차, 지역명+스카이차 대여 | 지역명+스카이차 비용, 지역명+간판작업 스카이차 | 주소·작업 높이·날짜로 배차 상담 |
| 서울·경기·인천 허브 3개 | 광역지역+스카이차 대여 | 지역별 비용, 배차 조건, 현장 준비사항 | 상세 지역 안내 또는 전화 상담 |

검색량·전환율·난이도의 실측 데이터는 없다. 위 검색어는 서비스 적합성을 기준으로 선택한 가설이다. 사용자가 알려준 네이버 '스카이차가격' 2위는 사용자 제공 관찰이며 독립적인 순위 측정을 완료한 것은 아니다. '스카이차비용' 미노출의 단일 원인을 메타 태그 부족으로 확정하지 않는다.

## 적용 범위

메인 1개, 가격표 1개, 서울 25개 구, 경기 수원·안양·군포, 서울·경기·인천 허브: 총 33개.

- 각 페이지의 title, description, OG, Twitter, canonical을 일관되게 구성했다. 지역 메타데이터는 지역별 소개 문맥을 활용한다.
- 가격표의 기존 `/pricing` URL과 제목의 '스카이차 가격표'를 유지하고 비용·견적 의도를 추가했다. '스카이차비용' 정확 표기는 제목·설명·본문·FAQ에 포함하며, 본문은 자연스러운 띄어쓰기도 사용한다.
- 비용 결정 요소, 장비 선택, 간판 시공비와 대여료의 차이, 이용 시간·추가비용 FAQ를 추가했다. FAQ JSON-LD는 화면에 펼쳐 볼 수 있는 동일 문답에서 생성한다.
- 간판작업 콘텐츠는 작업 높이·거리·진입로·설치 공간 등 대여에 필요한 정보를 제공한다. 간판 제작/시공까지 포함하는 상품을 임의로 만들지 않았다.
- 공통 메뉴 링크가 초기 서버 HTML에 나타나도록 수정했다. 메뉴 로고의 H1을 일반 텍스트로 바꿔 페이지 본문 H1만 남겼다.
- 수원·안양·군포의 강남 소개·FAQ 상속 오류를 수정했다.
- 없는 지역 페이지로 연결하던 링크는 해당 허브의 배차 문의 안내로 변경했다. 실제 상세 내용이 없는 페이지를 대량 생성하지 않았다.
- 인천 중구와 서울 중구의 슬러그를 구분했다. 잘못된 광역/도시 조합은 404, 실제 중첩 주소는 기존 평면 URL로 308을 반환한다.
- 가상의 지역 지점처럼 보일 수 있는 중복 LocalBusiness 정보를 제거하고 공통 Organization 및 지역 Service로 정리했다. 확인되지 않은 실시간 재고 표시와 존재하지 않는 `/search` SearchAction을 제거했다.
- 다른 모든 페이지에도 홈을 가리키던 hreflang 상속을 제거했다. 한국어 단일 언어 사이트의 페이지별 canonical은 유지한다.
- 변경한 페이지의 sitemap lastModified를 실제 작업일로 갱신했다. Googlebot·네이버 Yeti를 허용하는 robots 정책과 소유권 인증값은 유지한다.
- 모바일 확대 제한과 터치 확대 차단 코드를 제거했다.

## 가격 정책에 관한 보수적 처리

기존 코드에는 가격표 '부가세 포함', 지역 '부가세 별도', 표의 초과요금 15만/20만원과 하단 '5만원'이 공존했다. 금액을 새로 정하지 않고 기존 가격표 수치는 유지했다. 초과요금은 장비별 표를 참조하도록 수정하고, 세금은 '부가세 포함 여부와 추가 비용을 구분한 최종 결제금액 확인'으로 통일했다. 이는 세금 정책 확정이 아니므로 실제 포함/별도 정책은 운영자가 확인하여 추후 명시해야 한다.

## 검증

- TypeScript 검사 통과.
- Next.js 배포용 빌드 성공, 정적 페이지 생성 성공.
- `python3 scripts/verify-seo.py http://localhost:3000`: 개발 서버 33개 대상 페이지 검사 통과.
- 배포용 서버에서도 같은 검사 통과: 고유 title/description, canonical, H1/main 각 1개, OG/Twitter 설명 일치, 초기 HTML 메뉴·전화 CTA, FAQ 본문/JSON-LD 일치, 지역 링크·앵커, 5개 리디렉션/404 사례.
- 모바일 390px 화면에서 가격표·수원 지역·홈 화면의 가로 넘침이 없음을 확인하고 비용 FAQ 펼침 동작을 검증했다. 데스크톱 인천 허브의 상담 연결도 확인했다. 이는 실측 Core Web Vitals 성적이 아니다.
- 브라우저 데이터 패키지의 오래된 데이터 경고는 남아 있으나 빌드 오류는 아니다. 기존 package-lock.json 변경은 이전 의존성 설치 작업에서 발생했다.

## 배포 후 확인할 항목

1. 실제 사이트에 배포한 뒤 이 검증 스크립트를 공개 URL 대상으로 다시 실행한다.
2. Google Search Console 및 네이버 Search Advisor에서 사이트맵 처리와 대표 URL 수집·색인 상태를 확인한다. 계정 권한 없이 제출 완료를 주장하지 않는다.
3. '스카이차가격/스카이차 가격'과 '스카이차비용/스카이차 비용', 지역·간판작업 검색어를 구분해 변경 전후의 노출·클릭·도착 URL을 비교한다. 계절성과 기기·지역 차이를 함께 본다.
4. 전화 클릭 수와 실제 유효 상담·예약 완료를 구분한다. 순위·유입·매출 상승은 보장하지 않는다.
5. 실제 작업 사례, 동의 받은 후기, 확정 가격·서비스 범위가 확보되면 해당 지역과 작업 본문을 보강한다. 가상의 실적·후기·평점을 만들지 않는다.
