## 1. 개요

### 1.1 제품 한 줄 정의
> **스카이차(고소작업차) 대여 이용료의 5%를 현금으로 돌려주는 서비스의 마케팅·전환 웹사이트.**

전화 또는 앱으로 스카이차를 예약하면, 작업 완료 후 이용료의 5%를 현금으로 페이백해 주는 것이 핵심 차별점이다. 웹사이트는 이 가치를 빠르게 전달하고 **전화 예약 / 앱 다운로드**로 전환시키는 것을 목표로 한다.

### 1.2 비즈니스 정보
| 항목 | 값 |
|---|---|
| 서비스명 | 5프로돌려주는스카이차 |
| 대표번호 | 1877-3924 (전화 예약·상담) |
| 문자수신전용 | 010-2497-2433 |
| 도메인 | https://www.5prosky.com |
| 앱 (Android) | Google Play — `com.steve.kim.sadariapp` |
| 앱 (iOS) | App Store — id `6747275589` |
| 운영 시간 | 24시간 |
| 서비스 지역 | 제주도를 제외한 전국 (수도권 집중) |

### 1.3 문서 목적
- 웹사이트의 목표·타깃·기능·디자인·SEO 요구사항을 한 곳에 정의한다.
- 신규 페이지/섹션 추가, 문구·디자인 변경 시 일관성 판단 기준으로 사용한다.

## 2. 목표 & 성공 지표

### 2.1 제품 목표
1. 방문자가 **0.3초 안에** 핵심 메시지("스카이차 이용료 5% 현금 페이백")를 인지한다.
2. 방문자를 **전화 예약(주)** 또는 **앱 다운로드(보조)**로 전환한다.
3. 지역 검색(로컬 SEO) 및 생성형 답변엔진(AEO/GEO)에서 잘 노출된다.

### 2.2 성공 지표 (KPI 후보)
- 전화 CTA 클릭률(`tel:` 링크), 앱 스토어 이동률
- 히어로 → CTA 스크롤 도달률
- 지역 키워드 검색 노출·유입 (예: "수원 스카이차 대여")
- 모바일 LCP < 2.5s (3G 기준)

> ⚠️ 실제 목표 수치는 운영 데이터 확보 후 확정 (TBD).

## 3. 타깃 사용자

### 3.1 주요 페르소나
| 페르소나 | 상황 | 니즈 |
|---|---|---|
| **현장 사장님 / 기사** | 간판·외벽·전기·에어컨·도장 등 고소작업 발주 | 빠른 배차, 투명한 요금, 비용 절감 |
| **1인/소규모 업체** | 여러 업체에 전화 돌리기 번거로움 | 원터치 예약, 확실한 혜택(현금 페이백) |
| **반복 이용 고객** | 자주 스카이차를 부름 | 누적 페이백, 친구 초대 보상 |

### 3.2 핵심 페인 포인트 (문제 제기 섹션 근거)
1. **전화 뺑뺑이** — 업체 찾아 여기저기 전화, 배차 대기
2. **부르는 게 값** — 업체마다 요금이 제각각, 신뢰 어려움
3. **남는 것 없이 끝** — 비싼 이용료만 내고 돌아오는 혜택 없음

| 가치 | 설명 |
|---|---|

| **투명 요금** | 톤수·시간 기준 사전 고정 요금 |

```
/ (홈)
├─ /whyhere        여긴 뭐야? — 서비스 소개·창업 스토리 (5% 페이백 상세)

├─ /pricing        요금 안내
├─ /marketplace    일거리 장터
├─ /marketing      업종별 마케팅 노하우
├─ /support        고객 지원 / 다운로드 가이드
└─ /locations
   ├─ /[region]    광역 지역 (seoul · gyeonggi · incheon) — 동적 생성
   ├─ /gangnam     강남구 (동 단위 전용 페이지)
   ├─ /anyang      안양시
   ├─ /suwon       수원시
   └─ /gunpo       군포시
보조: /sitemap.xml, /rss.xml
```

### 5.1 SEO 허브-스포크 구조
- **홈** = 넓은 클레임 + 지역명 텍스트 + 지역 페이지로 내부링크 (허브)
- **지역 페이지** = 동(洞) 단위 심층 콘텐츠 (스포크)
- 지역 데이터 원천: `src/lib/regionData.ts` (서울 25구 / 경기 남·북부 시·군 / 인천 10구 + 강남·안양·수원·군포 동 리스트)

## 6. 기능 요구사항

### 6.1 홈페이지 섹션 구조 (2026-07 리디자인)
전환 퍼널 순서로 구성한다. 각 섹션은 클라이언트 컴포넌트(애니메이션) 또는 서버 컴포넌트(SEO)로 구현.

| # | 섹션 | 컴포넌트 | 목적 | 핵심 요소 |
|---|---|---|---|---|
| 1 | **히어로** | `home/HeroSection.tsx` | 후킹·단일 메시지 | 실사진 배경+그라데이션, `5%` 초대형 강조, 단일 전화 CTA + 보조(앱) 링크, 경량 지갑 목업, 신뢰 칩 |
| 2 | **문제 제기** | `sections/ProblemSection.tsx` | 공감 | 3대 페인 카드 |
| 3 | **서비스(해결)** | `sections/ServiceSection.tsx` | 해결책 | 3단계(앱 접수→책임 배차→5% 자동 현금) + 5% 페이백 + 친구 초대 |
| 3-1 | **출동 가능 지역** | `sections/AreaSection.tsx` | 로컬 SEO | 실제 지역명 텍스트 + 지역 페이지 내부링크 (서버 컴포넌트) |
| 4 | **FAQ** | `sections/FaqSection.tsx` | 반론 처리 | 네이티브 `<details>` 아코디언 |
| 5 | **CTA** | `sections/CtaSection.tsx` | 행동 유도 | 전화(주)+앱(보조) |
| 6 | **푸터** | `common/Footer.tsx` | 정보 | 대표번호·문자번호 |

### 6.2 공통 컴포넌트
| 컴포넌트 | 역할 | 요구사항 |
|---|---|---|
| `Navigation` | 상단 고정 내비 | 로고, 메뉴, 모바일 햄버거/사이드바 |
| `FloatingDownload` | 하단 고정 바(모바일)/우측 플로팅(데스크톱) | **모바일 항상 노출**(전화 걸기 · 앱 다운로드), 데스크톱은 푸터 노출 시 숨김 |
| `Footer` | 하단 정보 | 브랜드·연락처 |

### 6.3 지역 페이지 (`/locations/*`)
- 지역별 히어로·요금표·톤수 가이드·예약 3단계·신뢰 요소·동네 리스트(`LocalAreaList`)
- 데이터는 `regionData.ts`에서 주입 (조작 없는 실제 지역명)

### 6.4 전환 채널 (모든 페이지 공통)
- **전화 예약(주)**: `tel:18773924` — 가장 강조되는 CTA
- **앱 다운로드(보조)**: 기기 감지 후 Google Play / App Store 분기

## 7. 디자인 시스템

> 기준: `.claude/skills/design-system` (토스페이먼츠 스타일 — 토큰 기반·구현 우선) + `docs/toss_tip` (카피 5원칙)

### 7.1 브랜드 & 토큰
| 토큰 | 값 | 용도 |
|---|---|---|
| `color.brand` | `#F97316` | 주 CTA·강조 (2026 리브랜드: 민트→주황) |
| `color.brand.hover` | `#EA580C` | hover |
| `color.brand.tint` | `rgba(249,115,22,.12)` | 칩 배경 |
| `color.surface.dark` | `#0B0B0C` | 히어로/CTA 배경 |
| `type.hero.value` | `clamp(2.75rem,9vw,4.5rem)` / 800 | `5%` 숫자 |
| `type.title` | `font-jalnan`, `clamp(1.5,5vw,2.25rem)` / 700 | 섹션 헤딩 |
| `radius.card` / `radius.cta` | 16px / 9999px(pill) | 카드 / 버튼 |
| `motion` | 200ms ease-out, stagger 120ms | reduced-motion 대응 필수 |

- 타이포: 제목 **잘난체(Jalnan)**, 본문 시스템 폰트.

### 7.2 카피 원칙 (toss_tip 5원칙)
1. **단일 메시지** — 핵심 하나만 (5% 현금)
2. **확실성** — "최대" 지양, "무조건 · 바로" 강조
3. **가벼운 동사** — "가입" 대신 "예약/시작"
4. **숫자 구체화** — 24시간, 5%, 5만원
5. **쉬운 단어** — "페이백/캐시백" → "현금으로 돌려드려요"

### 7.3 컴포넌트 상태 규칙 (must)
모든 인터랙티브 요소는 default / hover / **focus-visible** / active 상태를 정의한다.
- 주 CTA: `focus-visible` 링(3px `#FDBA74`), 터치 타깃 ≥ 48px, hover `translateY(-1px)`, active `scale .98`.

## 8. 접근성 (WCAG 2.2 AA)

| 요구 | 기준 (테스트 가능) |
|---|---|
| 텍스트 대비 | ≥ 4.5:1 (어두운 오버레이로 보장) |
| 포커스 | 모든 인터랙티브 요소 `focus-visible` 링 노출 (키보드 Tab 확인) |
| 시맨틱 | 섹션 `aria-labelledby` + 헤딩 위계 h1→h2→h3 |
| 이미지 | 장식 `alt=""`, 의미 있는 이미지 서술형 alt |
| 모션 | `prefers-reduced-motion` 시 애니메이션 정지 |
| 터치 | 버튼·링크 ≥ 48px |

## 9. SEO / AEO / GEO 전략

### 9.1 온페이지 SEO
- 지역명 실제 텍스트 노출(크롤 가능), 허브-스포크 내부링크
- 홈 `AreaSection`은 **순수 서버 컴포넌트**(JS 없이 텍스트 렌더)
- 키워드: 지역별 "○○ 스카이차 대여/가격/요금표", 5% 페이백, 고소작업차 등 (`layout.tsx` metadata)

### 9.2 구조화 데이터 (JSON-LD)
- `LocalBusiness` 스키마: 이름·전화·이메일·운영시간·결제수단·`areaServed`(국가(제주 제외)+서울/경기/인천+핵심 도시)·`hasOfferCatalog`
- 검색엔진 인증: naver / google / daum 사이트 검증 태그 포함

### 9.3 원칙 (무결성)
- **후기·별점·누적 건수 등 수치는 실제 데이터일 때만 사용.** 없으면 비수치 신뢰 요소로 대체.
- 가짜 지역 페이지·키워드 스터핑 금지 (실제 서비스 지역만 노출).

## 10. 기술 스택 & 아키텍처

| 항목 | 내용 |
|---|---|
| 프레임워크 | Next.js **16.0.7** (App Router, Turbopack dev) |
| 언어 | TypeScript, React 19 |

| 슬라이더 | swiper 11 |
| 렌더링 | 홈·대부분 정적(Static), `/locations/[region]` SSG, `/rss.xml` 동적 |

### 10.1 디렉터리 규칙
- 공통 컴포넌트: `src/components/common`
- 홈 섹션: `src/components/home/sections`
- 페이지별 컴포넌트: 해당 라우트 디렉터리 (예: `src/app/locations/gangnam/components`)
- 파일: 컴포넌트 PascalCase, 라우트·유틸 kebab/lowercase
- 지역 데이터: `src/lib/regionData.ts`

### 10.2 전화번호 링크 규칙
- 전역 `a[href^="tel:"]` 스타일이 있으며, 자체 레이아웃이 필요한 링크는 `.tel-raw` 클래스로 예외 처리.
