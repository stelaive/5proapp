## 구현 중 판단

추가 판단과 검증 결과는 작업 중 이 문서에 이어서 기록합니다.

### 2026-11-10 · 구현

- 공통 컴포넌트의 스타일을 바꾸는 대신 가격 페이지 전용 헤더·푸터·CSS Module을 만들었다. 다른 지역 페이지의 표와 메뉴에 영향을 주지 않기 위해서다.
- 계산기는 기본값을 기존 첫 요금제인 1톤~3.5톤·반나절로 설정했다. 선택한 장비에 단시간 공개 요금이 없으면 반나절로 바꾸고 변경 이유를 즉시 알린다. ‘공개 요금 없음’을 ‘서비스 불가’로 단정하지 않는다.
- 가격표는 900px 미만에서 7종 모두 카드로 전환했다. 단시간·반나절·하루뿐 아니라 추가 시간당·월대 요금도 누락하지 않는다.
- 기존 긴 설명은 ‘비용과 장비 선택’ 펼침 영역과 FAQ로 정리했다. 내용은 서버에서 렌더링하고 기존 `#equipment-prices`, `#cost-guide`, `#answer-summary` 앵커를 유지한다.
- 페이백 지급 방식은 기존 고객센터에 기재된 ‘작업 완료 → 앱 포인트 적립 → 출금 신청’을 따랐다. 시안의 ‘결제 즉시 계좌 자동 입금’으로 확대하지 않았다.
- 헤더의 앱 다운로드는 실제 두 스토어 링크가 있는 하단 안내로 이동한다. 모바일 CTA도 기존 주요 행동인 앱 다운로드·전화 상담을 유지한다.
- 견적 복사는 현재 선택·기준 요금·페이백 예시·최종 견적 확인 문구를 함께 복사한다. 브라우저가 자동 복사를 막으면 직접 선택할 텍스트를 제공한다. 외부 전송은 없다.
- 메뉴는 모바일에서 펼침 방식으로 제공하고 Escape로 닫을 수 있도록 했다. 계산기는 기본 라디오 입력을 사용해 키보드로도 조작할 수 있다.
- 핵심 본문은 등장 애니메이션 없이 처음부터 표시한다. 스크립트 로딩이나 화면 진입 감지 실패로 요금표가 숨겨지는 상황을 방지한다.

## 후속 요청 · 모바일 요금 카드 슬라이드 (2026-11-10)

- 사용자 요청: PC 디자인은 유지하고 모바일 장비별 이용요금을 첨부 이미지처럼 왼쪽으로 넘기는 카드형으로 변경.
- 적용 범위: 기존 카드형이 표시되던 900px 미만의 장비별 이용요금 영역만 변경했다. 900px 이상 PC 비교 표와 계산기, 나머지 섹션은 유지한다.
- 카드 7장을 세로로 나열하는 대신 한 줄의 가로 스와이프 영역으로 배치한다. 다음 카드 일부가 보여서 넘길 수 있음을 알 수 있게 했다.
- 이미지처럼 이동 화살표와 현재 위치 점을 제공하되 카드의 가격을 가리지 않도록 카드 아래에 배치했다. 현재 카드 번호(1/7)와 안내 문구도 제공한다.

- 새 라이브러리 없이 브라우저 기본 가로 스크롤과 CSS 스냅을 사용한다. 터치·트랙패드, 화살표 버튼, 위치 점, 키보드 방향키/Home/End로 이동할 수 있게 한다.
